# Week 4: Conditional Statements and Functions

This week's practice uses conditional statements and functions to make decisions, organise code, and return useful values.

## Topics

- relational and logical operators
- comparing strings
- `if`, `elif`, and `else`
- `try`/`except` for introductory runtime errors
- defining and calling functions
- parameters, local variables, and return values
- global constants
- standard-library functions and modules

## Activities

1. Complete the five files in `exercises/beginner/`.
2. Answer the questions in [think-about-it.md](think-about-it.md).
3. Complete the three files in `exercises/intermediate/`.

Run an activity from the repository root with, for example:

```text
python week-04/exercises/beginner/exercise_01_number_category.py
```

Solutions are in `solutions/`. Try each activity before opening the matching solution.
