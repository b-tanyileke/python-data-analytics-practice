# Week 5: Iteration, Strings, and Files

This week's practice uses loops to repeat work, strings to work with text, and
files to save and read information.

## Topics

- `while` and `for` loops
- `break` and `continue`
- running totals and sentinels
- finding the largest and smallest values
- nested loops
- string indexing, slicing, testing, and manipulation
- reading from and writing to text files

## Activities

1. Complete the five files in `exercises/beginner/`.
2. Answer the questions in [think-about-it.md](think-about-it.md).
3. Complete the three files in `exercises/intermediate/`.
4. Use [hints/README.md](hints/README.md) only when a small nudge is needed.

Solutions are in `solutions/`. Try each activity before opening the matching
solution.

## Check your work

After writing your functions, run the following command from the repository
root:

```text
python -m pytest week-05/check_your_work.py
```

These checks use the files in `exercises/` and report which functions are
working. A failure is feedback for debugging, not a grade.

The separate files in `tests/` verify the included sample solutions and are
used to maintain the repository.
