# Week 10: Data Cleaning and Preparation

These optional, ungraded activities follow the sample final's multiple-choice
and short-answer format.

## Part A: Multiple choice

Answer the questions in [multiple-choice.md](multiple-choice.md), then check
the [answers](solutions/multiple-choice-answers.md).

## Part B: Short-answer coding

Complete Questions 9–12 in `exercises/`. Each combines several cleaning or
transformation operations. Try each question before looking at its solution in
`solutions/`; use [hints](hints/README.md) if needed.

After installing the repository requirements, run the optional self-checks
from the repository root:

```text
python -m pytest week-10/check_your_work.py
```

These checks use your functions and provide feedback, not a grade. The
separate `tests/` folder verifies the sample solutions.
