# Week 9: pandas Basics

This optional, ungraded practice follows the sample final's format: multiple
choice followed by short-answer coding questions. Week 8 has no new content.

## Part A: Multiple choice

Choose the best answer for each question in [multiple-choice.md](multiple-choice.md).
Answers are in [solutions/multiple-choice-answers.md](solutions/multiple-choice-answers.md).

## Part B: Short-answer coding

Complete Questions 9–12 in `exercises/`. Each question includes an example
and combines pandas basics. Try the questions before looking at the visible
solutions in `solutions/`; use [hints](hints/README.md) when needed.

Install the repository requirements as described in the root README, then
check your own functions from the repository root:

```text
python -m pytest week-09/check_your_work.py
```

These optional checks are feedback, not a grade. The separate `tests/` folder
checks the sample solutions for repository maintenance.
